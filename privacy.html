Privacy Policy

Hermes Agent is a personal, single-user application operated by its owner for their own use.

Data accessed

With the owner's explicit consent, the app accesses the owner's own Google Calendar, Drive, Sheets, Docs, Gmail and Contacts data via Google APIs, solely to carry out tasks the owner requests.

Data storage and sharing

OAuth tokens are stored only on the owner's own computer. The app does not collect data from other users, does not sell or share Google user data with third parties, and does not use it for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
